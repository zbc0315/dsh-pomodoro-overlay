# DSH Pomodoro Overlay — 设计说明

## 目标

为 DeepSeek Harness Web 设计一个低干扰、自动运行的番茄钟插件：

- 新计时或已运行的计时无需点击即自动进入「专注 → 休息 → 专注」循环；旧版暂停快照按原状态保留，不自动恢复运行。
- 在 DSH 设置窗口的独立「番茄钟」页配置时钟字体，以及两种阶段的时长、颜色与数字不透明度。
- 倒计时铺满当前聊天消息区域，但不覆盖侧栏、顶部导航和底部输入框。
- 默认字体为等线（DengXian），专注为浅灰 10% 不透明度，休息为红色 30% 不透明度；用户可保存自定义外观。

## 界面范围与层级

“铺满对话框”定义为聊天消息区域，而非整个浏览器窗口。大数字居中并以不裁剪为前提尽量放大，保持数字原有长宽比。

倒计时是低干扰装饰层：

- 整个聊天 overlay 均为 `pointer-events: none`，不阻断消息选择、滚动、链接和输入操作。
- 聊天区不提供暂停、跳过、重置或工具条，也不显示“专注 / 休息”可见阶段标签；只保留大倒计时。
- 设置页控件使用 DSH 主题语义令牌，保证正文、焦点和控件对比度。
- 不用 emoji 作为结构图标；设置页优先文字按钮或内联 SVG。
- 不用闪烁、缩放或持续脉冲动画。阶段切换仅允许短暂颜色过渡，并尊重 `prefers-reduced-motion`。

## 视觉令牌

| 角色 | 实现方向 |
| --- | --- |
| 专注大数字 | 默认 `#9ca3af` + 10% 不透明度；颜色与不透明度均可配置 |
| 休息大数字 | 默认 `#ef4444` + 30% 不透明度；颜色与不透明度均可配置 |
| 字体 | 默认等线（DengXian），支持自定义单本机字体名称与常用候选；无远程字体请求，保留 `font-variant-numeric: tabular-nums` |
| 数字尺寸 | 根据聊天区实际宽高和文本测量结果自适应；可用宽度为区域宽度减 32px，可用高度为区域高度减 64px，两者最低均按 32px 计算 |
| 控件 | 使用 `--dsw-alias-*` 背景、边框、正文和品牌色令牌 |
| 动效 | 默认克制；减少动态效果偏好下取消非必要过渡 |

大数字按用户要求保持半透明，因此它被当作装饰性视觉信息，不作为唯一的无障碍信息来源。屏幕阅读器仍可获取阶段名称和剩余时间，设置页控件使用正常对比度；剩余时间不以 `aria-live` 每秒播报，避免读屏干扰。

## 状态与交互

默认配置：字体等线；专注 25 分钟 / `#9ca3af` / 10% 不透明度；休息 5 分钟 / `#ef4444` / 30% 不透明度。

- **首次启动**：没有有效快照时，原生配置 ready 后按默认 25 分钟开始专注阶段；已保存快照按原状态恢复。
- **自然结束**：运行中的计时自动切换到另一阶段，无限循环。
- **纯展示**：聊天区不提供暂停、继续、跳过或重置入口；运行中的阶段按时间线推进，旧版暂停快照保持暂停。
- **修改配置**：当前计时不打断；字体、颜色和不透明度保存后立即生效，新时长从下一阶段生效。
- **刷新、切标签页、浏览器休眠**：运行中显示值由 `Date.now()` 与绝对截止时间计算；暂停时使用保存的剩余时间。二者都不依赖 `setInterval` 累减。
- **关闭后重开**：恢复持久化状态；运行中已过期的阶段按时间线推进到当前应有阶段，暂停快照不自动推进。
- **多标签页**：通过 `storage` 事件同步运行或暂停状态，各标签页不分别累计计时。

## 配置约束

- 专注时长：整数，1–240 分钟，默认 25。
- 休息时长：整数，1–240 分钟，默认 5。
- 两种阶段颜色：六位十六进制 `#RRGGBB`，使用原生颜色选择器并显示色值文本。
- 两种阶段数字不透明度：0–100% 整数滑杆，显示当前百分比；0% 完全透明，100% 不透明。
- 时钟字体：默认等线（DengXian），两种阶段共用；允许 1–80 字符的单个本机字体名称，不接受引号、逗号或 CSS 声明，未安装时回退本机字体栈。
- 设置位于 DSH 设置窗口独立「番茄钟」页；七个字段一次原子保存并携带 revision。
- 草稿预览只影响设置页，保存前不得改变聊天区；配置保存应有明确反馈，非法输入不能污染运行状态。
- 超长阶段仍使用“分钟:秒钟”格式（例如 `120:00`），数字尺寸随字符数重新适配。

## 验收场景

1. 首次安装启动后自动开始，不需要额外点击。
2. 默认配置下，工作阶段为浅灰半透明，休息阶段为红色半透明；不显示可见阶段文字，屏幕阅读器仍可获取阶段。
3. 大数字仅覆盖聊天消息区，不遮挡侧栏和输入框，不阻断消息操作。
4. 修改周期后当前阶段不被打断，下一阶段采用新值。
5. 聊天区不显示暂停、跳过、重置或工具条，且 overlay 全部鼠标穿透。
6. 运行中的计时在页面切到后台再返回、刷新页面后，剩余时间与实际经过时间一致；暂停快照仍显示保存的剩余时间。
7. 模拟运行中的一次性跨阶段，恢复到当前正确阶段，不重复补发历史提醒；暂停快照不被自动推进。
8. 两个标签页中的阶段、剩余时间和运行或暂停状态通过 `storage` 事件同步。
9. 浅色、深色、窄屏和减少动态效果模式下均可用；设置页表单可键盘操作。
10. DSH 设置窗口出现独立「番茄钟」导航；七个字段可键盘编辑，草稿预览正确，保存后外观立即应用且当前 `endsAt` 不变；字体切换后数字重新适配且不裁切。
11. 插件卸载或 HMR 清理后，计时器、事件监听器、样式和 DOM 均被释放。
