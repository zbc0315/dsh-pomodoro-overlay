# 设计：番茄钟改为全局视口时钟（2026-11-17）

## 意图与原因

用户反馈（m00410）：右侧边栏展开时番茄钟自动缩小；且不在对话界面时番茄钟消失。
诉求：时钟铺满整个 DSH Web 全局界面，任何视图都显示，布局变化不影响其尺寸。

## 方案（唯一合理路径）

时钟已挂在全局 overlay（`shell.overlay`，fixed），只是几何锚定聊天区。改为视口全矩形：

- 时钟矩形 = 整个浏览器视口；不再测量聊天 DOM、不再扣除 composer、不再要求 `data-chat-flow`。
- 任何视图（设置页、TODO 板、空白会话等）只要配置 ready 即显示。
- 已知代价：半透明数字会压在侧栏、顶栏、输入框、弹窗内容之上；保持 `pointer-events: none`，可看穿点穿。
- 计时状态机、七项设置、颜色/透明度/字体、无可见控制按钮等全部不变。不新增配置项。

## 放弃的备选

- 保留聊天区锚定 + 忽略边栏变化：不满足"不在对话界面也要有"。
- 新增"锚定模式"设置项：用户没有要求可切换，增加设置面复杂度，不做。

## 改动范围

- `src/chat-geometry.js` → 改为视口几何（或废弃，直接在 client 用视口尺寸）。
- `src/client.js` → 去掉聊天锚定/隐藏逻辑，resize 监听保留。
- `tests/chat-geometry.test.js` → 改为视口几何断言。
- 文档四份 + `package.json`/`package-lock.json` 版本 → `0.1.3`。
- 生效方式：重新构建 client bundle 后浏览器刷新即可，无需重启 Host。

## 验收

- 展开/收起右侧栏，数字尺寸不变。
- 离开对话界面（设置页等），时钟仍在。
- 半透明数字覆盖在侧栏/顶栏之上但鼠标可穿透。
- `npm run verify` 37/37 通过。
